Operator Manual Ocelot VirtualServer

A Go control plane that schedules workloads across registered compute nodes, manages persistent volumes, and drives instance lifecycle through a state-machine reconciler.

module github.com/mgdavisxvs/Ocelot · package virtualserver

Overview

Ocelot VirtualServer sits between a workload catalog (BitTorrent tracker) and a pool of compute nodes. Operators declare Services — desired-state workload manifests — and the control plane places, starts, and restarts instances on Nodes until the service's restart policy is satisfied.

The system is a single Go binary embedding SQLite (WAL mode). There are no external message queues or distributed consensus components; the database is the sole source of truth.

Note

All write operations to the database are serialised through a single mutex. Horizontal scaling of the control plane is not supported; run exactly one instance per SQLite file.

Architecture

Four subsystems cooperate at runtime:

API
HTTP Control Plane
Bearer-token-authenticated REST API at /v1/. Reads and mutates all resource types. Snapshot and restore run as tracked async operations.
SCH
Scheduler
Filters nodes through 8 hard constraints then scores survivors on 5 dimensions. Returns a single PlacementDecision.
REC
Reconciler
Ticks on a configurable interval (default 5 s). Drives instances through the state machine; applies restart policy; tears down mounts on exit.
DB
SQLite Store
17 idempotent IF-NOT-EXISTS migrations. Single connection, WAL mode, SetMaxOpenConns(1).

Plugin boundaries are BackendAdapter (container runtimes, VMs) and StorageDriver (volume backends). Both ship as Go interfaces registered before Start.

Server Config

Construct a Config and call virtualserver.New:

import "github.com/mgdavisxvs/Ocelot/virtualserver"

vs, err := virtualserver.New(virtualserver.Config{
    DBPath:            "/var/lib/ocelot/vs.db",
    ListenAddr:        ":8080",
    BearerToken:       "changeme",
    ReconcileInterval: 5 * time.Second,
    // PrometheusRegisterer: myReg, // defaults to prometheus.DefaultRegisterer
}, slog.Default())

Registering Plugins

Call RegisterAdapter and RegisterStorageDriver before Start. If no adapter is registered, Start falls back to NoOpAdapter (dry-run mode).

vs.RegisterAdapter(myDockerAdapter)
vs.RegisterStorageDriver(myNFSDriver)
vs.SetCatalog(myTorrentCatalog) // optional; omit to skip artifact gating
Warning

Registering a duplicate adapter or driver name panics. Each Name() value must be unique across its registry.

Namespaces provide logical isolation for Services and Volumes. All resources belong to exactly one namespace; the default namespace must be created before any other resource.

Nodes

A Node represents a registered compute host. Nodes must send heartbeats to stay in the scheduler candidate pool.

Heartbeats

Nodes must PUT /v1/nodes/{id}/heartbeat periodically. The scheduler's health score decays to 0 if last_heartbeat is more than ~150 s old.

Services

A Service is a desired-state manifest. The reconciler continuously creates and restarts Instances to satisfy it.

{
  "id":               "svc-inference",
  "namespace":        "production",
  "name":             "llm-inference",
  "image":            "registry/llm:v2",
  "cpu_millicores":   4000,
  "ram_bytes":        17179869184,
  "gpus": [{ "count": 1, "vram_per_device": 42949672960, "model_filter": "A100" }],
  "restart_policy":   "Always",
  "node_selector":    { "region": "us-west" },
  "volume_mounts": [{ "name": "weights", "volume_id": "vol-weights", "mount_path": "/models" }],
  "artifact_hash":    "aabbcc..."
}
restart_policyBehaviour
AlwaysReschedule on any exit (success or failure).
OnFailureReschedule only when exit state is failed.
NeverTerminal — no rescheduling.

artifact_hash: when set, the reconciler queries the CatalogProvider before provisioning. If the torrent swarm is unavailable (0 seeders), the instance is deferred until the next reconcile tick.

Instances

An Instance is a single running (or recently terminated) copy of a Service. The reconciler drives it through the following state machine:

scheduled
→
provisioning
→
starting
→
running
→
stopping
→
stopped
↘ on failure
failed
StateReconciler action
scheduledCall adapter.Provision; advance to provisioning or mark failed.
provisioningCall adapter.Start; advance to starting.
startingPoll adapter.Status; advance to running when ready.
runningPoll adapter.Status; detect exit → stopping or failed.
stoppingPoll until stopped; advance to stopped, then apply restart policy.
stoppedTerminal (unless restart policy triggers reschedule).
failedTerminal (unless OnFailure or Always triggers reschedule).

Stopping an instance

POST /v1/instances/{id}/stop. The reconciler will call adapter.Stop on the next tick and transition the instance to stopping.

Volumes

Volumes are persistent storage resources managed by a StorageDriver. A volume is bound to exactly one node once its first instance mounts it (node affinity).

Snapshots

Snapshot and restore are async. The API returns an Operation record immediately; poll GET /v1/operations/{id} until state is succeeded or failed.

# trigger snapshot
POST /v1/volumes/{id}/snapshot

# restore a snapshot to a new volume
POST /v1/volumes/{id}/restore/{snapshotID}

# poll the operation
GET /v1/operations/{operationID}
Warning

Deleting a volume while any instance has it mounted returns 409 Conflict. Unmount all instances first.

Operations

Long-running control-plane actions (snapshot, restore) are tracked as Operation records.

StateMeaning
pendingEnqueued, not yet started.
runningIn progress.
succeededCompleted successfully. message contains the result handle.
failedCompleted with error. message contains the reason.

Scheduler

The scheduler evaluates every ready node against eight hard constraints, then scores passing nodes on five dimensions to pick the best fit.

Hard constraints (all must pass)

01
Node state
Node must be in ready state.
02
Architecture
node_selector.arch must match node arch.
03
Label selectors
All keys in node_selector must be present on the node with equal values.
04
Node exclusions
Node ID and name must not appear in node_exclusions.
05
CPU headroom
Node's free millicores (total − allocated) must ≥ service cpu_millicores.
06
RAM headroom
Node's free RAM (total − allocated) must ≥ service ram_bytes.
07
GPU VRAM & model
Each GPURequirement must find enough free GPUs matching count, VRAM, and model filter.
08
Volume affinity
All volumes with a node_affinity must agree on a single node (conflicting affinities reject all nodes).

Scoring dimensions

DimensionWeightDescription
CPU utilisation25 %Higher allocated fraction → higher score (bin-packing).
RAM utilisation25 %Same bin-packing logic for memory.
GPU utilisation20 %Fraction of GPU device slots in use.
Health15 %Decays linearly from 1.0 (fresh heartbeat) to 0.0 at ~150 s stale.
Reliability15 %1 − (recent_failures × 0.2), clamped to [0, 1]. Counts failed instances in the last 24 h.

Reconciler

The reconciler runs a tight loop at ReconcileInterval. Each tick processes all instances that are not in a terminal state, advancing each one step through the state machine by calling the appropriate BackendAdapter method.

Volume mount lifecycle

During provisioning, the reconciler calls resolveMounts for each VolumeMount in the service. This:

  1. Looks up the storage driver by volume.driver_name.
  2. Calls driver.Mount(ctx, handle, instanceID).
  3. On the first mount of a volume, records node_affinity in the DB.
  4. Persists a VolumeBinding record linking the instance to the volume.

On instance exit (teardownMounts), driver.Unmount is called for every binding and the binding records are deleted.

Catalog Gating

If a Service has a non-empty artifact_hash, the reconciler calls CatalogProvider.ClassifyArtifact(hash) before provisioning. The result determines whether to proceed:

ArtifactStatusSeedersAction
available≥ 3Proceed with provisioning.
degraded1–2Proceed with provisioning.
unavailable0Skip this tick; retry on the next reconcile cycle.

Wiring the Ocelot tracker

vs.SetCatalog(virtualserver.OcelotCatalogAdapter(func(hash string) int {
    // return current seeder count from the tracker in-process
    return tracker.TorrentList[hash].Seeders
}))

The adapter accepts a func(string) int closure to avoid a circular import between virtualserver and tracker.

Storage Drivers

Implement storage.StorageDriver and register it before Start:

type StorageDriver interface {
    Name()       string
    Create(ctx context.Context, volumeID string, sizeBytes int64) (VolumeHandle, error)
    Delete(ctx context.Context, handle VolumeHandle) error
    Mount(ctx context.Context, handle VolumeHandle, instanceID string) (*MountPoint, error)
    Unmount(ctx context.Context, handle VolumeHandle, instanceID string) error
    Stat(ctx context.Context, handle VolumeHandle) (*VolumeStats, error)
    Snapshot(ctx context.Context, handle VolumeHandle) (VolumeHandle, error)
    RestoreFrom(ctx context.Context, snapshotHandle VolumeHandle) (VolumeHandle, error)
}

VolumeHandle is an opaque string alias. The LocalDriver (built-in) uses the absolute path of the volume directory as its handle.

Tip

Delete must return an error if any instance currently has the volume mounted. Check your implementation's mount-reference counting before allowing deletion.

Backend Adapters

Implement BackendAdapter to plug in a container runtime, VM hypervisor, or any workload executor:

type BackendAdapter interface {
    Name() string
    Provision(ctx context.Context, inst *Instance, svc *Service,
              node *Node, mounts []ResolvedMount, gpuIDs []string) error
    Start(ctx context.Context, inst *Instance) error
    Stop(ctx context.Context, inst *Instance) error
    Status(ctx context.Context, inst *Instance) (InstanceState, string, error)
    Deprovision(ctx context.Context, inst *Instance) error
}

NoOpAdapter is the built-in no-op implementation; it always returns success and advances instances to running immediately. It is activated automatically when no real adapter is registered.

Signals & Lifecycle

Pass a cancellable context to Start. When the context is cancelled, Start returns and the caller should invoke Stop:

ctx, cancel := context.WithCancel(context.Background())
go func() {
    sigCh := make(chan os.Signal, 1)
    signal.Notify(sigCh, os.Interrupt, syscall.SIGTERM)
    <-sigCh
    cancel()
}()

if err := vs.Start(ctx); err != nil {
    log.Fatal(err)
}
shutdownCtx, done := context.WithTimeout(context.Background(), 30*time.Second)
defer done()
vs.Stop(shutdownCtx)

Stop gracefully shuts down the HTTP server (drains in-flight requests) and closes the SQLite connection. Allow at least the HTTP server's WriteTimeout (60 s) for graceful drain.

Note

The reconciler loop exits when its context is cancelled — it does not wait for in-flight adapter calls to finish. Use your adapter's own timeout logic for safe teardown.
